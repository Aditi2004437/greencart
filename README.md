# greencart
 GreenCart - Eco-Friendly Marketplace
A multi-vendor eCommerce platform for sustainable, handmade, and upcycled products. Built with WordPress & WooCommerce.

Features
✔️ Multi-Vendor Marketplace – Allow multiple sellers using Dokan or WC Vendors.
✔️ WooCommerce Integration – Full eCommerce functionality with cart, checkout, and payments.
✔️ Carbon Footprint Tracking – Show environmental impact per product.
✔️ Green Shipping Options – Support eco-friendly delivery methods.
✔️ Social Impact Dashboard – Track waste saved & sustainability impact.

🚀 Installation Guide
1️ Set Up Locally Using LocalWP
Download & Install LocalWP on your system.
Create a New Site and name it GreenCart.
Select Custom Setup → Choose PHP 8+ & MySQL.
Click Start Site and log in to WordPress Admin (/wp-admin)

2 Install WordPress Plugins
WooCommerce
Dokan (for multi-vendor functionality)
Elementor (for custom design)
WPForms (for contact forms)
